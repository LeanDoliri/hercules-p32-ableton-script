Los canales se muestran como los ve Ableton en el modo de mapeo (Ctrl+M): 1 a 16. Entre paréntesis, el número que usa el código del script (0 a 15). Toda nota que no figure en este mapa la captura el script y no llega a ninguna pista; los CC no mapeados quedan libres para asignar a mano.

Script y mapa por LeanDoliri
Código, manual de usuario y guía de instalación en github.com/LeanDoliri/hercules-p32-ableton-script. Cualquier persona con un Hercules P32 DJ y Ableton Live puede instalarlo siguiendo el README.
Basado en el script generado con Remotify para el P32 (2017) y reescrito a mano sobre el framework _Framework de Ableton Live. Hercules y P32 DJ son marcas de Guillemot Corporation; este proyecto no está afiliado a Hercules ni a Ableton.
